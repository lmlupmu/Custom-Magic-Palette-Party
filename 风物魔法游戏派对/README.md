# 风物魔法调色派对

> 大别山乡土风物 AI 文创小游戏 · 大学生 AI 应用创新大赛参赛作品
> 赛道：**AI + 艺术文创应用**

纯 HTML + CSS + JavaScript 实现的 2D 网页游戏，零依赖、零构建，浏览器打开即玩。

## 项目简介

立足河南信阳大别山农林本土风物（信阳毛尖、山茶花、板栗、南湾鱼、罗山甜柿、映山红……），探索 AI 赋能乡土数字文创：用户通过休闲消除小游戏收集风物线稿，再用「AI 调色工坊」一键完成多风格艺术上色、生成国风小诗，产出**信阳主题明信片**与**毛尖茶叶礼盒封面**等文创作品并下载保存。

## 功能模块

### 1. 首页
项目介绍与创作引导，国风青绿 UI。

### 2. 消除小游戏（8 关）
- 点击两张相同风物卡片即可消除，全部消除即通关
- 难度平缓递增（4 对 → 16 对），适合现场演示
- 通关解锁对应风物**黑白线稿** + **信阳乡土科普**
- 误点计数 + 三星评级（最佳成绩本地存档）

### 3. AI 调色文创工坊（核心模块）
- **12 种风物线稿**：茶叶 / 山茶花 / 板栗 / 茶罐 / 麦穗 / 杜鹃花 / 南湾鱼 / 甜柿 / 荷花 / 银杏 / 香菇 / 春笋
- **4 套艺术色调**：春日青绿 · 秋意赭黄 · 国潮艳彩 · 淡雅水墨
- **AI 魔法生成**：模拟 AI 上色流程，同步生成适配风物的国风小诗（打字机效果）
- **48 首内置小诗**（12 风物 × 4 风格）
- **上传我的风物**：支持上传自己的图片并起名，AI 分析名字生成**藏名小诗**，照片按风格套艺术滤镜
- **双文创预览**：信阳主题明信片（竖排诗 + 邮票框）/ 毛尖茶叶礼盒封面（圆形插画 + 印章）
- **一键下载**：Canvas 高分辨率重绘，导出 PNG 到本地

### 4. 关于页面
项目赛道、背景、功能简介、AI 应用说明，供评审阅读与截图。

## 快速开始

无需安装任何依赖，任选其一：

```bash
# 方式一：直接双击 index.html

# 方式二：本地静态服务（推荐）
npx http-server .        # 或
python -m http.server    # 然后访问 http://localhost:8000
```

## 数据持久化

使用浏览器 `localStorage` 本地存档，刷新/关闭不丢失：

| 键 | 内容 |
|---|---|
| `wm_unlocked` | 已解锁的风物线稿 |
| `wm_levels` | 已通关关卡进度 |
| `wm_stars` | 每关最佳星级 |
| `wm_custom` | 用户上传的自定义风物（图 + 名） |

> 存档与浏览器绑定；`file://` 与 `http://localhost` 的存档相互独立。

## 技术要点

- 全部插画为**手写 SVG 矢量线稿**，上色 = 调色板分区填充，黑白线稿 = 同一组路径留白描边
- AI 小诗：内置 48 首风物诗库 + 名字哈希选模板的**藏名诗生成器**（同名人同诗，不同人不同诗）
- 自定义图片：Canvas 压缩至 900px 入库，按风格施加 CSS/Canvas 滤镜模拟 AI 风格化
- 下载：Canvas 2D 高分辨率重绘（明信片 1200×760 / 礼盒 1000×1000），竖排诗逐字排版
